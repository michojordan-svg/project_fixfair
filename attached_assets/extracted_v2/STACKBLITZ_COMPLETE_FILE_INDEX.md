SUPPORT & HELP
=====================================

If you encounter issues:

1. **Module not found errors**
   - Check file paths match exactly
   - Verify all folders created
   - Check spelling in imports

2. **Styles not applying**
   - Verify theme.ts is imported
   - Check className names
   - Look for CSS syntax errors

3. **App not rendering**
   - Check index.html has <div id="root">
   - Verify main.tsx imports App correctly
   - Look for circular imports

4. **Navigation not working**
   - Check onNavigate prop passed
   - Verify screen names match
   - Look for typos in component names
